MyLM — Rudimentary Next-Word Learning (2D) + Chat Idle

Next-word toy model: each word has a 2D vector. For a context word prev, candidates are scored by score = v(prev) · v(candidate). Training pushes the true next word to score higher than a random negative.

Model: score(prev, cand) = v(prev) · v(cand) p = σ(score) Training (negative sampling, 1 negative): Phase A: compute score/p for (prev → trueNext) and one random negative. Phase B: update vectors to increase p(true) and decrease p(neg). This is a deliberately tiny “how weights learn” toy, not a full LLM.
